ExampleOS security advisory EXA-2026-0042

Published 2026-11-05. Example Networks has fixed a flaw in the web console of ExampleOS router firmware before 4.2.7. An attacker on the local network could change router settings without signing in. Example Networks is not aware of exploitation. Update to 4.2.7 or later.
